# Support

- **Wrong effort for a turn?** Open a [misrouted turn](https://github.com/vadympetryshyn/effort-pilot/issues/new?template=misrouted.yml) issue with what `/effort-pilot classify <message>` shows.
- **A bug?** Open a [bug report](https://github.com/vadympetryshyn/effort-pilot/issues/new?template=bug.yml).
- **A question, a setup to share, an idea?** Use [Discussions](https://github.com/vadympetryshyn/effort-pilot/discussions).
- **A vulnerability?** Report it [privately](https://github.com/vadympetryshyn/effort-pilot/security/advisories/new).
